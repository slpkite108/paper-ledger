논문대장 개인정보 안내

논문대장은 브라우저에서 실행되는 연구실적 정리 앱입니다.

Google 연결 시 계정의 이름·이메일·계정 식별자를 표시하고, Google Drive 앱 전용 저장소에 사용자가 저장한 저자 즐겨찾기, 양식 프리셋(열·서식·정렬·추가 기준표), OpenAlex API 키를 보관합니다. 일반 Drive 문서 접근 권한은 요청하지 않습니다. Google의 단기 로그인 토큰은 만료 시점까지 현재 탭의 세션 저장소(sessionStorage)에 보관합니다. 함께 저장하는 정보는 만료 시각, 계정 식별자와 공개 클라이언트 ID입니다. 새로고침 시 Google에서 계정을 확인해 연결을 복원합니다.

Google에 저장한 키는 해당 계정의 접근 제어로 보호되는 앱 전용 데이터이며 별도의 앱 비밀번호 암호화는 적용하지 않습니다. 사용 시 브라우저 메모리로 읽어 OpenAlex에 전송합니다. 키와 로그인 토큰은 GitHub 저장소·CSV·localStorage에 기록하지 않습니다. OpenAlex 키는 sessionStorage에도 기록하지 않고, 연결 복원 후 Google 저장소에서 다시 불러옵니다.

Google 미연결 상태의 즐겨찾기와 양식 프리셋은 해당 브라우저의 로컬 저장소에 보관됩니다. 논문 편집 내용은 탭의 메모리에 유지되며 CSV 다운로드는 사용자의 기기에 저장됩니다. Google 연결 전후의 즐겨찾기는 자동으로 병합하지 않습니다.

Google 데이터 삭제는 앱의 즐겨찾기 삭제·프리셋 삭제·Google 키 삭제 기능을 이용합니다. 연결 종료·인증 만료·인증 거부 시 이 탭의 메모리와 sessionStorage에 보관한 인증 정보를 삭제합니다. 클라우드 데이터는 삭제하지 않습니다. 브라우저의 탭 복원 기능으로 세션이 유지될 수 있으므로 공용 기기에서는 연결 종료를 사용하세요. 브라우저 즐겨찾기는 앱에서 삭제하거나 브라우저 사이트 데이터를 지우면 삭제됩니다.

검색어·저자 식별자·DOI와 조회에 필요한 API 키는 OpenAlex 또는 Crossref에 전송됩니다. Google API 사용에는 Google의 약관과 개인정보처리방침이, 호스팅에는 GitHub의 정책이 적용됩니다. 이 앱은 별도의 광고·분석 추적기를 사용하지 않습니다.

Tech Science Press 출판일 자동 보완 시 공개 DOI만 별도 출판일 API(paper-ledger-publication-dates.slpkite108.chatgpt.site)에 전송합니다. API는 출판사 공개 페이지의 날짜와 출처를 반환하고 24시간 캐시합니다. Google 계정·토큰·OpenAlex 키·편집 내용은 이 API로 전송하지 않습니다. API 호스팅에는 Sites 제공자의 정책이 적용되며 서비스 제공 및 요청 제한을 위해 네트워크 접속 정보가 처리될 수 있습니다.

서비스 운영 관련 문의는 저장소 문의 페이지에서 할 수 있습니다. 공개 문의에 개인정보나 API 키를 게시하지 마세요.
