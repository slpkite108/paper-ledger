# 논문대장

여러 저자의 논문을 검색하고 사용자가 만든 양식으로 연구실적을 정리하는 정적 웹 앱입니다.

웹 앱: https://slpkite108.github.io/paper-ledger/

## 사용

논문 페이지 상단의 **국내 특허 검색** 링크를 누르면 별도 특허 검색 페이지(`#/patents`)로 이동합니다. 직접 접속 주소는 https://slpkite108.github.io/paper-ledger/#/patents 입니다. 발명자·출원인·특허명·출원번호 중 하나 이상 입력하고 **KIPRIS에서 검색**을 누르면 입력 조건이 KIPRIS 새 창으로 전달됩니다. KIPRIS의 검색 버튼을 눌러 결과를 확인하세요. 여러 항목은 AND 조건으로 적용하며, 국내 출원번호는 13자리(하이픈 허용)를 입력합니다. 논문 페이지와 특허 페이지 사이를 이동해도 같은 탭의 입력·선택·편집 상태는 유지됩니다. 새로고침하면 저장하지 않은 상태는 초기화됩니다.

현재 특허 결과를 앱 안으로 가져오는 API는 연결되지 않았습니다. 특허 페이지의 **API 이용 신청 안내**에서 KIPRIS Plus 발급 절차를 확인할 수 있습니다. API 이용 권한 발급과 별도 연동이 완료되어야 앱 내 결과 조회가 가능합니다.

1. 저자 이름·ORCID·OpenAlex ID를 검색하고 여러 저자를 선택합니다.
2. 참여교수 표기명과 연도를 정한 뒤 논문을 불러옵니다.
3. arXiv 제외(기본 꺼짐), 같은 제목·같은 유형 최신 1편(기본 켜짐), 학술유형 필터를 사용합니다.
4. 저자 즐겨찾기에 목록과 조회 조건을 저장합니다. Google 미연결 시 해당 브라우저에 저장합니다.
5. **양식·프리셋**에서 Excel 머리글을 붙여넣고, 열 이름·순서·데이터 연결·고정값·논문별 사용자 항목을 구성합니다. 기본 17항목도 불러올 수 있습니다.
6. 글자 크기·열 너비·셀 정렬·숫자/백분율/연월 형식·머리글 색·줄바꿈·교차 행 배경을 지정합니다. 최대 3개 기준으로 정렬하고 열 머리글로도 순서를 바꿀 수 있습니다. 빈 값은 오름/내림차순 모두 마지막입니다. 출판년월은 연도 → 월의 시간순으로 비교합니다. **오래된 순 ↑**은 `2024-12 → 2025-01 → 2025-12 → 2026-01`, **최신 순 ↓**은 그 역순입니다. 월 미상은 같은 연도에서 월이 확인된 자료 뒤에 둡니다. 출판년월에 연결한 사용자 양식 열에도 같은 비교를 적용하며, 같은 연월이면 다음 정렬 기준을 사용합니다.
7. 프리셋에는 열·서식·정렬·선택한 인정 기준과 추가 기준표가 저장됩니다. Google 연결 시 Google Drive 앱 저장소에, 미연결 시 이 브라우저에 저장합니다. JSON 파일로 프리셋을 주고받을 수 있습니다. 기존 브라우저 프리셋은 연결 후 다시 저장하면 Google에 저장됩니다.
8. 논문명을 눌러 서지정보와 사용자 항목을 수정합니다. **내 양식 표**에서 결과를 확인하고 **Excel 다운로드**로 서식을 포함한 XLSX를 받습니다. CSV에는 값만 포함됩니다. 선택·표시된 행이 현재 정렬 순서로 내보내집니다.

## 저자·소속 확인

OpenAlex의 저자 ID에도 동명이인·약칭으로 인한 잘못된 논문 연결이 있을 수 있습니다. 논문 편집 화면에서 **논문에 기재된 저자·소속**과 **선택한 저자의 최근 소속**을 비교할 수 있습니다. 두 소속 또는 논문 원자료의 ORCID가 다르면 목록에 **소속·저자 확인 필요**가 표시됩니다. 소속 이동·겸임 가능성이 있으므로 이 표시만으로 논문을 제외하지는 않습니다.

원문으로 다른 저자임이 확인된 연결 오류는 해당 논문과 해당 저자 조합에 한해 목록·CSV·Excel에서 제외하며, **불러온 자료의 저자 확인**에서 제목·사유·출처를 확인할 수 있습니다. 2026-09-17 확인: DOI `10.1016/j.jmaa.2025.130131` 및 동일 논문의 arXiv판 `10.48550/arXiv.2510.05493`에 기재된 B. Shin은 성균관대학교 수학과 Bomi Shin입니다. 인하대학교 Byeong-Seok Shin(`A5061420652`)의 실적으로 연결한 OpenAlex 오류를 보정합니다. 다른 저자 프로필에서 이 논문을 찾는 경우에는 이 보정을 적용하지 않습니다. 근거: [원문 마지막 페이지](https://arxiv.org/pdf/2510.05493#page=17), [성균관대학교 연구자 소개](https://swb.skku.edu/aorc/research_fellows.do?articleNo=25635&mode=view).

## 인정 기준 자료 (조사일: 2026-09-16)

**인정 기준·자료 선택**에서 CS 자료를 우선 제공하며, 다른 분야·기관 자료도 선택하거나 Excel 표로 추가할 수 있습니다. 기본값은 CS BK21 목록입니다. ‘최신’은 이번 조사에서 확인한 공개 자료의 판을 뜻하며 실시간 갱신이 아닙니다.

- CS BK21: [한국과학기술한림원 2026-03-23 공식 공고](https://kast.or.kr/kr/notice/notice.php?bbs_data=aWR4PTIzNDE4JnN0YXJ0UGFnZT0wJmxpc3RObz00ODgmdGFibGU9JmNvZGU9bm90aWNlJnNlYXJjaF9pdGVtPSZzZWFyY2hfb3JkZXI9%7C%7C&bgu=view&cate=&code=notice&idx=23418)의 첨부 목록 188개와 인정 IF를 수록했습니다. **공고 연도가 목록의 개정연도라는 뜻은 아닙니다.** 최신 공고에서 재사용한 자료이며 제출 기관의 적용 범위를 확인해야 합니다.
- CS 한국정보과학회: [공식 우수학술대회 안내](https://aisociety.kr/sub/sub_04_02.php)에 게시된 2024 개편 목록(216개) 링크를 제공합니다. [2026-05-22 학회 공지](https://kmms.or.kr/board/news/article/276662)는 연구재단 공식 인정 논의 중이라고 설명합니다. 학회 우수 등급을 BK 인정으로 자동 대체하지 않습니다.
- SCIE: [Clarivate Master Journal List](https://mjl.clarivate.com/)에서 ISSN과 Science Citation Index Expanded 색인명·수록기간을 확인합니다. IF가 있다는 사실만으로 SCIE라고 판정하지 않습니다. 현재 수록 상태와 출판 당시 수록 상태는 다를 수 있습니다.
- h5-index: [Google Scholar Metrics 공식 안내](https://scholar.google.com/intl/en/scholar/metrics.html)에 표시된 2025년 7월판(2020–2024 발행 논문)을 기준으로 CS/전 분야 검색 링크를 제공합니다. h5는 학술지·학술대회 지표이며 저자 h-index와 다릅니다. 미수록을 50 미만으로 간주하지 않습니다.

**인정 구분 자동 입력**은 기본 켜짐입니다. 선택 저자를 조회하거나 DOI 출판정보가 보완되면 사용 중인 기준표와 대조하고 구분·근거·기준연도를 함께 기록합니다. 화면, 현재 정렬된 CSV와 Excel에 같은 결과가 들어갑니다. 자동 일치는 직접 검토 완료를 뜻하지 않습니다. 기존 직접 입력한 구분과 근거는 유지합니다. 자동 설정과 자료 선택은 양식·프리셋에 저장됩니다.

- SCIE 자동 범위: [IEEE 2026년 8월 공식 Title List](https://open.ieee.org/wp-content/uploads/IEEE-Title-List-August-2026.xlsx)의 Index가 SCIE인 167종, [CMC](https://www.techscience.com/cmc/info/Indexed), [CMES](https://www.techscience.com/CMES/info/Indexed), [Applied Intelligence](https://link.springer.com/journal/10489)의 공식 출판사 색인 안내 3종과 Clarivate MJL에서 2026-09-16에 개별 확인한 5종(Scientific Reports, Journal of Biomedical Informatics, Journal of Mathematical Analysis and Applications, Biomedical Signal Processing and Control, Human-centric Computing and Information Sciences)입니다. 총 175종의 일부 목록이며 전 분야 전체 SCIE 목록이 아닙니다. 현재 수록 상태의 확인 자료이며 과거 출판연도별 수록을 보증하지 않습니다. IF만 있는 ESCI 자료는 포함하지 않습니다.
- CS 자동 범위: 위 BK 목록 188개입니다. 구분에는 **CS우수학술대회**, BK 근거에는 목록명·공식 첨부 출처·코드를 남깁니다. 한국정보과학회 권장 목록은 자동 판정·BK 근거로 사용하지 않습니다. BIBM의 현 명칭은 [공식 CFP](https://www.ieeebibm.org/BIBM2025/image/BIBM2025-call-for-papers.pdf)로 확인한 별칭을 추가했습니다. 학회 권장 목록에서 BK 인정 여부를 가져온 것이 아닙니다.
- h5 자동 범위: 사용자가 확인하여 추가한 Metrics 기준표입니다. **학술대회**이고 h5가 50 이상일 때만 **h5-index 50 이상 학술대회**를 입력합니다. 저자 h-index나 저널 h5를 이 구분에 사용하지 않습니다. Google Metrics 실시간 전체 수집은 연결되어 있지 않고 내장 h5 수치를 추측해서 넣지 않습니다.

SCIE는 저널의 ISSN 우선, 그 외는 정규화한 전체 명칭·명시된 별칭이 일치할 때 대조합니다. ISSN이 서로 다르면 제목이 같아도 적용하지 않습니다. 알려진 약칭 괄호만 제거하므로 본 학회 이름을 포함한 워크숍·Findings·포스터를 본 학회로 합치지 않습니다. 여러 후보가 나오거나 자료가 없으면 미확인입니다. 제출 기관의 실제 발표 트랙·논문 요건은 별도로 확인하세요. 수동 검토·반영도 계속 사용할 수 있습니다.

다른 자료는 Excel에서 **학술지명 / ISSN / 약칭 / 구분 / 값 / 인정 IF** 머리글과 행을 복사하여 추가합니다. 이름·기준연도·공식 출처 URL이 필요합니다. 구분은 SCIE, BK인정, CS우수학술대회, h5-index, 참고 중 하나이며 h5 값은 정수입니다. 최대 10개 기준표, 각 30,000행입니다. CSV/TSV 파일(UTF-8, 10MB 이하)도 가져올 수 있습니다. Journal Title / ISSN / eISSN / Web of Science Index 머리글을 인식합니다. Index 열이 있으면 SCIE 또는 Science Citation Index Expanded를 명시한 행만 가져오고 ESCI·SSCI·빈 값은 제외합니다. 색인 열이 없는 공식 SCIE 전용 파일은 **SCIE 전용 목록**을 선택하세요. IF는 SCIE 판정에 사용하지 않습니다. 똑같은 행은 한 번만 저장합니다. 자료 최신판 및 적용 범위는 사용자가 확인합니다.

기준표에서 찾지 못한 저널은 **SCIE 근거 미확인 · 기준표 확인 필요**로 표시하며, 사용자가 근거와 함께 비해당으로 확인한 경우와 구분합니다. 각 저널 행의 **SCIE 공식 확인** 링크에서 ISSN으로 MJL을 조회할 수 있습니다. 전체 색인 목록 다운로드는 현재 Web of Science 구독자를 대상으로 합니다([공식 다운로드](https://mjl.clarivate.com/collection-list-downloads), 2026-09-16 확인). 파일을 가져오면 해당 프리셋에서 자동 대조하며 공개 저장소로 전송하지 않습니다. 앱은 공식 전체 목록을 실시간 수집하지 않습니다.

기존 프리셋이 모든 내장 자료를 사용하고 있었다면 새 Clarivate 확인 목록을 한 번 추가합니다. 일부 자료만 선택한 프리셋과 자동 대조를 끈 설정은 유지합니다. 수동 선택 드롭다운은 검색 결과 100개까지 표시하며, 자동 대조는 기준표 전체를 대상으로 합니다.

논문 편집에서도 SCIE/BK 결과와 h5 값·기준연도·출처·메모를 기록할 수 있습니다. 양식에서 ‘SCIE 확인 결과’, ‘BK 확인 결과’, ‘학술지·학술대회 h5-index’, ‘인정 근거·기준연도’를 연결하면 내보내기에 포함됩니다.

## 월 단위 탐색 범위

시작·종료 연도와 월을 각각 선택한 뒤 **선택 저자 논문 불러오기**를 누릅니다. 예를 들어 2025년 5월부터 2025년 5월까지는 5월만, 2025년 11월부터 2026년 2월까지는 연도를 넘는 기간을 포함합니다. 전체 월은 시작 쪽 1월, 종료 쪽 12월로 처리하며, 연도가 비어 있으면 해당 방향의 제한이 없습니다. 연도를 지우면 월도 해제됩니다.

월은 Crossref·출판사 자동 보완 또는 직접 지정한 **현재 출판년월**을 기준으로 비교합니다. 양 끝 월을 모두 포함하고 기간·유형 필터 후 같은 제목·같은 유형의 최신 1편을 선택합니다. CSV/XLSX에도 현재 기간에서 표시·선택된 행과 정렬을 그대로 적용합니다. 월 범위와 월 미상 옵션은 저자 즐겨찾기에 저장됩니다. 예전 즐겨찾기는 전체 월로 복원됩니다.

**기간 경계의 월 미상 포함**은 기본 켜짐입니다. 예를 들어 2025년 5월만 조회할 때 `2025`처럼 월이 없는 자료도 포함하며 월 미상 표시는 유지합니다. 이 옵션을 끄면 제외합니다. 그 연도 전체가 범위에 포함되면 월을 몰라도 기간 안에 있으므로 유지합니다. 연도까지 없는 자료는 기간이 지정된 경우 이 옵션을 따릅니다.

후보 수집은 OpenAlex 수록 연도 전체를 조회합니다. 월로 서버 후보를 좁히지 않아 OpenAlex의 임시 1월 날짜 때문에 실제 5월 자료가 빠지는 것을 방지합니다. OpenAlex와 출판사의 **연도 자체가 다른 경우**에는 조회 연도를 넓혀 확인하세요. 다음 논문 불러오기는 처음 적용한 기간을 유지하며, 자동 보완 중에는 결과 행 수가 달라질 수 있습니다.

## 학술유형·중복 처리

- 출처가 학술대회면 conference로 분류합니다. OpenAlex article만으로 저널이라고 단정하지 않습니다.
- DOI가 있는 문헌은 Crossref에서 출판일과 유형을 자동 확인합니다(arXiv 제외). ‘출판일·학술유형 재확인’으로 다시 조회할 수 있습니다. 직접 지정한 유형·날짜는 유지합니다.
- 제목은 Unicode NFKC, 대소문자, 연속 공백을 정규화합니다. 같은 참여교수·같은 제목·같은 학술유형 중 최신 기준일 1편을 표시합니다. 날짜가 같으면 OpenAlex ID로 일정하게 결정합니다.
- 같은 제목의 학술대회판과 저널판은 각각 유지합니다. 유형 미확인 문헌도 알려진 유형에 합치지 않습니다. 저널 행에는 불러온 자료에 동일 제목의 학술대회가 있으면 표시합니다. 제목 일치 표시는 실제 확장판 관계의 확정을 뜻하지 않습니다.
- 기간·유형 필터를 먼저 적용한 뒤 같은 유형의 중복을 합칩니다. 원본 조회 행을 삭제하지 않으므로 옵션을 끄면 다시 표시됩니다. 제목이 다르면 자동으로 합치지 않습니다.
- arXiv는 주 출처·DOI·원문 주소로 판단합니다. 학술지 게재본의 보조 arXiv 링크만으로 제외하지 않습니다.
- 필터는 현재까지 불러온 결과에 적용합니다. 페이지당 저자별 100편이며, 다음 논문 불러오기로 더 가져옵니다. CSV에는 현재 표시되고 선택된 행만 포함합니다.

## 학술대회 명칭·개최일

학술대회는 **개최 시작일**을 출판년월 열·정렬·기간 필터·Excel/CSV의 기준으로 사용합니다. Crossref event.name/start/end뿐 아니라 출판사가 등록한 ConferenceInfo의 conference_name/acronym/start_date/end_date/year를 읽습니다. 따라서 book-chapter라도 학술대회 정보가 확인되면 Conference로 분류하고, 논문집 시리즈 대신 학술대회 명칭을 표시합니다. 직접 수정한 유형·명칭·날짜는 유지합니다.

개최 월을 확인하지 못하고 개최 연도만 있으면 연도만 표시합니다. 개최일 자료가 없으면 **개최일 미확인**으로 두며 책 발행일이나 온라인 출판일로 대신 채우지 않습니다. 논문 편집의 날짜 근거에 개최기간과 별도 출판일을 함께 보관합니다. 양식에 학술대회 명칭·개최기간·논문집명 열을 추가할 수 있습니다.

확인 사례: [Differential Privacy for Personalized Federated Learning Based Hypernetworks](https://link.springer.com/chapter/10.1007/978-981-96-5693-6_46)는 CSA 2024 학술대회 논문입니다. [공식 논문집 안내](https://link.springer.com/book/10.1007/978-981-96-5693-6)와 Crossref ConferenceInfo의 개최기간은 **2024-12-18~20**, 온라인 출판일은 **2025-05-15**입니다. 이 앱의 기준 연월은 **2024-12**이므로 2025~2026 기간 필터에서는 제외됩니다. 후보 수집은 OpenAlex 출판연도 기준이므로, 개최연도와 출판연도가 다른 논문을 찾을 때는 조회 연도를 넓혀 확인하세요.

## 출판년월과 Cite 인용정보

- 저널은 **저널 출판일 기준**에서 **권·호 발행일 우선**(기본값) 또는 **온라인 게재일 우선**을 선택합니다. 두 종류가 모두 확인되면 선택 기준을 사용하며, 한 종류만 확인되면 그 날짜를 사용하고 대체 적용 이유를 표시합니다. 같은 종류 안에서는 출판사 확인 자료를 우선합니다. 출판사 일반 Published/citation_publication_date와 Crossref published/issued는 그 자체로 권·호일이나 온라인일을 뜻하지 않으므로, 종류가 명확한 날짜가 없을 때만 ‘종류 미확인 출판일’로 사용합니다. 연도만 있으면 연도를 유지하며 다른 날짜의 월을 섞지 않습니다.
- DOI 등록일·메타데이터 수정일·접수일·게재 승인일은 저널 출판일로 대신 사용하지 않습니다. 학술대회는 위 개최일 기준을 적용합니다. 권·호일과 온라인일이 다르면 전체 화면의 기준 선택을 사용하세요. 논문별 날짜를 직접 지정하면 ‘기준 예외’로 보관되며 자동 조회와 전체 기준 변경으로 덮어쓰지 않습니다. 편집창의 **자동 기준으로 되돌리기**로 예외를 해제할 수 있습니다.
- 날짜 아래에 근거를 표시합니다. 양식에 **출판일 근거** 열을 추가하면 출처도 Excel/CSV로 내보낼 수 있습니다. 직접 입력하거나 ‘이 날짜 적용’으로 지정한 값은 자동 재확인으로 덮어쓰지 않습니다. ‘자동 기준으로 되돌리기’로 해제합니다.
- 날짜 확인 중에는 내보내기가 잠시 비활성화됩니다. 확인을 중단하면 완료된 보완 결과를 유지하고 다시 내보낼 수 있습니다. 조회 연도는 OpenAlex의 수록 연도 기준이며, 보완된 출판일과 연도가 달라질 수 있습니다.
- **Cite / 인용정보에서 날짜 가져오기**에서 출판사 페이지 또는 인용파일 URL을 직접 조회할 수 있습니다. 출판사가 교차 출처 읽기(CORS)를 허용할 때만 작동합니다. 연결이 막히면 출판사 Cite 메뉴의 RIS/BibTeX 파일 또는 브라우저에서 저장한 논문 페이지 HTML(1MB 이하)을 가져오거나 내용을 붙여넣으세요. 미리보기 날짜를 확인한 뒤 **이 날짜 적용 → 변경사항 반영**을 누릅니다.
- RIS의 DA/Y1/PY, BibTeX의 date 또는 year/month, HTML의 citation_publication_date/online_date/date/year를 읽습니다. DOI가 현재 논문과 일치하는 단일 논문 자료만 적용합니다. 인용정보에 연도만 있으면 월은 복원할 수 없습니다. 일반 APA 인용문이나 PDF는 이 가져오기 형식에 포함되지 않습니다. 가져온 HTML은 실행하지 않으며 파일 내용은 외부로 전송하지 않습니다.
- 확인 사례(2026-09-16): **Defending against Backdoor Attacks in Federated Learning by Using Differential Privacy and OOD Data Attributes**, DOI `10.32604/cmes.2025.063811`. OpenAlex는 `2025-01-01`, Crossref와 출판사 RIS는 연도 `2025`만 제공합니다. [출판사 원문](https://www.techscience.com/CMES/v143n2/61439)의 Issue published와 HTML citation_publication_date는 **2025-05-30**이므로 이 DOI에 출판사 근거를 수록하여 **2025-05**를 적용합니다. Tech Science Press DOI는 자동 조회하며 다른 출판사는 Crossref와 인용정보 가져오기를 사용합니다.

- 추가 확인 사례: [Global-Local Embedding Gating Network](https://www.techscience.com/cmc/v88n2/67650), DOI `10.32604/cmc.2026.080992` → **2026-06-15**. [Multi-Stage Hierarchical Feature Extraction](https://www.techscience.com/cmc/v83n3/61059), DOI `10.32604/cmc.2025.063815` → **2025-05-19**. 출판사 HTML 날짜와 Issue published가 일치합니다(2026-09-16 확인).
- 전용 API에는 DOI만 보내며 Google 계정·토큰·OpenAlex 키는 보내지 않습니다. 미지원 DOI나 출판사 차단·요청 제한 시 날짜를 추측하지 않고 기존 근거를 유지합니다.

## Google 계정으로 사용

Google 연결 설정이 앱에 적용되어 있습니다. 사용자가 별도의 ID를 입력할 필요는 없습니다.

1. 웹 앱의 **검색 설정 → Google 계정으로 연결**을 누릅니다.
2. 사용할 Google 계정을 선택하고 앱 전용 저장 권한을 허용합니다.
3. 즐겨찾기·양식 프리셋을 저장하면 해당 계정의 Google Drive 앱 전용 저장소에 보관됩니다.
4. OpenAlex 개인 키를 계정에 보관하려면 **Google에 저장**을 누릅니다. **이 탭에 적용**은 메모리에만 보관합니다.
5. 페이지 상단에서 **Google 연결됨 / 연결 복원 중 / 재연결 필요 / 미연결** 상태와 연결된 이메일을 확인합니다. 상태 표시를 누르면 Google 설정이 열립니다.

일반 Drive 문서 접근 권한은 요청하지 않습니다. 같은 탭에서 새로고침하면 유효한 Google 연결을 복원하고 계정에 저장된 검색 키를 다시 불러옵니다. 단기 로그인 토큰은 만료 시점까지 이 탭의 sessionStorage에 보관하며, 연결 종료·만료·인증 거부 시 삭제합니다. 토큰이 만료되면 상단에 재연결 필요가 표시됩니다. 연결 종료를 누르면 브라우저 저장 모드로 돌아갑니다. ‘이 탭에 적용’만 한 검색 키와 편집 중인 논문은 새로고침 후 복원하지 않습니다.

Google 저장 키는 Google 접근 제어와 HTTPS로 보호하며 앱 자체의 추가 비밀번호 암호화는 없습니다. 저장된 키·즐겨찾기·프리셋은 앱에서 각각 삭제할 수 있습니다. 브라우저에 저장했던 항목은 Google 연결 후 다시 저장하면 해당 계정으로 옮길 수 있습니다. 브라우저의 탭 복원 기능으로 세션이 유지될 수 있으므로 공용 기기에서는 연결 종료를 눌러 주세요.

파일을 더블클릭한 HTML 앱에서는 브라우저 저장 기능을 사용하며, Google 연결은 GitHub Pages의 HTTPS 주소에서 사용합니다.

## 배포

GitHub Pages는 저장소의 **main 브랜치 /docs 폴더**를 배포합니다. Settings → Pages → Deploy from a branch → main /docs로 설정합니다.
화면은 정적 앱이며 Tech Science Press 출판일 자동 보완에는 별도로 배포한 공개 읽기 전용 API를 사용합니다. 조회에는 인터넷이 필요하고 각 서비스의 사용 한도가 적용됩니다.
소스는 src/에 있습니다. Node.js 22.13 이상에서 npm ci, npm run check, npm run build를 실행하고 갱신된 docs/도 함께 커밋합니다. 자세한 내용은 [개발·배포 안내](DEVELOPMENT.md)를 참고하세요.

## 데이터

API 키, 로그인 토큰, 사용자 정보는 GitHub에 업로드하지 않습니다. 논문 편집 내용·검토 결과·사용자 입력값은 탭 안에서만 유지하므로 Excel/CSV로 저장하세요. 프리셋은 논문 행을 저장하지 않습니다. SCIE·BK·IF 등의 최종 인정 여부는 선택한 기준 자료와 기관 지침·원문을 대조하세요.


## OpenAlex에서 누락된 논문의 확인 보완

저자 선택은 OpenAlex에서 하며 논문 불러오기는 OpenAlex와 활성화한 등록 저널을 함께 조회합니다. ORCID 입력은 OpenAlex 저자를 식별하는 데 사용하며 ORCID의 업적 목록을 별도로 수집하지 않습니다. ‘조회 완료’와 조회 건수는 해당 검색원의 결과 수집 상태이며 저자의 모든 논문을 확보했다는 뜻은 아닙니다. DOI 조회는 이미 찾은 논문의 정보를 보완하므로 저자 검색 누락을 해결하지 못합니다. 기본 논문 불러오기는 등록 저널도 자동 조회합니다. ‘저널 후보 확인’에서 저자별 결과를 검토한 뒤 추가합니다.

등록하지 않았거나 전용 연결이 없는 저널의 누락은 남을 수 있습니다. SCIE 판정과 논문 수집은 별개입니다. 원문과 저자 식별자를 확인한 일부 누락 자료를 내장해 저자 조회 결과에 함께 보완합니다. 출판사 전체에 대한 실시간 검색은 아닙니다. 보완 행은 ‘출판사 확인 보완’ 링크와 원문 발행일 근거를 표시하고, OpenAlex 조회 수와 별도로 집계합니다. 동일 참여교수·학술유형·DOI가 나중에 OpenAlex에도 나타나면 기존 행과 편집값을 유지하여 중복 추가를 막습니다.

현재 보완 사례: **Accelerating the Cloud-Based Visualization System for Digital Twin Applications: BVH-Based Rendering Optimization**, DOI **10.22967/HCIS.2025.15.005**. [출판사 원문](https://hcisj.com/articles/?HCIS202515005)은 **2025-01-30**, HCIS volume 15, article 05, Eun-Seok Lee / Byeong-Seok Shin을 명시합니다. 페이지 24–41은 [KCI 서지정보](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003220804) 기준입니다. 2026-09-16 확인 당시 DOI 등록기관은 KISTI이며 OpenAlex DOI/제목 검색 결과가 없고 Crossref DOI 조회는 404였습니다.

현재 보완은 인하대 Byeong-Seok Shin의 확인된 OpenAlex ID A5061420652 또는 ORCID 0000-0001-7742-4846 선택 시 적용합니다. 이름만 같은 후보에게는 추가하지 않습니다. 발행일이 2025년 1월이므로 **2025년 9월~2026년 8월** 범위에서는 제외되는 것이 맞습니다. 직접 확인 완료 표시는 사용자가 검토한 경우에만 설정합니다.

## 저널 추가 검색

1. 기존과 같이 저자를 선택하고 조회 연월을 설정합니다.
2. **저널 추가 검색**을 열어 저널명(선택)과 ISSN을 등록합니다. Crossref에서 ISSN을 확인한 저널을 추가할 수 있으며 HCIS는 전용 출판사 연결이 기본 제공됩니다. 검색할 저널을 체크하세요.
3. **선택 저자 논문 불러오기**를 누르면 활성화한 저널도 선택한 모든 저자명으로 자동 검색합니다. OpenAlex 조회가 실패해도 저널 검색은 진행합니다. **저널 후보 확인**에 미추가 후보·조회 실패·기간 제외 건수가 표시됩니다. 저자별 첫 페이지를 조회하므로 다음 페이지가 있으면 결과 창에서 이어서 확인하세요. 이름 표기가 다르면 선택 저자 한 명의 영문 이름을 바꿔 **등록 저널에서 찾기**로 다시 검색할 수 있습니다.
4. 후보의 소속과 OpenAlex ID도 표시됩니다. 같은 사람으로 보이는 여러 ID를 선택한 경우 어느 저자의 대장에 넣을지 확인하세요. 이름·소속·원문을 확인한 후보만 체크하고 **대장에 추가**합니다. 이름 일치는 동일 인물 확인을 뜻하지 않습니다. 추가한 행은 기존 정렬·기간·유형 필터와 Excel/CSV 내보내기를 따릅니다. 같은 참여교수·유형·DOI의 기존 행 및 편집값은 유지합니다.
5. 등록 저널 목록은 브라우저에 보관됩니다. Google 계정을 연결하고 저자 즐겨찾기를 저장하면 이 목록도 함께 저장·복원됩니다. 논문 행과 편집값은 계속 Excel/CSV로 별도 보관하세요.

기본 OpenAlex 조회를 다시 실행해도 저널 추가 행은 유지하며 적용 기간으로 필터합니다. 저자를 해제하면 해당 저자의 행도 제거됩니다. 저널 검색 대상 등록 자체로 SCIE가 인정되지는 않습니다. Crossref 수록분이 없는 저널에는 별도 출판사 연결이 필요하며, 임의의 웹주소만으로 모든 저널을 자동 수집하지는 않습니다. Crossref 저자 검색은 유사 이름을 포함할 수 있고, HCIS에서도 동명이인 확인이 필요합니다. 출처별 조회 실패는 표시하며 0건과 구분합니다.

2026-09-16 실제 HCIS 저자 검색에서 Byeong-Seok Shin 9편, 2025~2026년 범위 3편을 확인했습니다. 이 결과에는 BVH-Based Rendering Optimization(2025-01-30)이 포함됩니다. DOI를 입력하지 않고 저자 검색에서 발견하고, DOI는 원문에서 보완합니다.

기간에서 제외된 후보는 결과 창의 ‘기간 조건으로 제외된 후보’를 펼쳐 제목과 날짜를 볼 수 있습니다(검색원에서 조회한 연도 안의 결과 기준). 이미 대장에 있는 동일 DOI는 다시 추가할 수 없습니다. 후보는 확인 전까지 CSV/Excel에 포함되지 않습니다. 예시 논문 Out-of-distribution Detection by Quantifying the Uncertainty with the Stochastic Weight Ensemble은 HCIS 저자 검색으로 발견되며, 원문 발행일은 2025-03-30입니다. 2025~2026년 전체 범위에는 포함되고 2025-09~2026-08에는 제외됩니다.

## 출판일 기준을 일괄 적용하기

- 기준을 바꾸면 불러온 저널의 표시 연월, 기간 포함 여부, 최신 동일 제목 병합, 정렬과 CSV/Excel이 함께 바뀝니다. 저널 후보 창의 포함·제외 결과도 보관된 후보에서 다시 계산합니다. 학술대회 개최일은 바뀌지 않습니다.
- 각 저널 행에 권·호일과 온라인일을 따로 표시하고, 선택 기준 적용 / 다른 날짜로 대체 / 종류 미확인 / 날짜 미확인 / 직접 지정 예외를 구분합니다. 하나만 있는 날짜는 선택 기준과 달라도 사용합니다. DOI 등록일·수정일·접수일·승인일은 대체 날짜가 아닙니다.
- 설정은 브라우저에 보관되며 저자 즐겨찾기와 양식 프리셋에도 저장됩니다. 기존 즐겨찾기·프리셋의 기본값은 권·호 발행일 우선입니다.
- 양식에 **권·호 발행일 (원본)**, **온라인 게재일 (원본)**, **출판일 적용 기준** 열을 추가할 수 있습니다. 기본 출판년월 열은 선택 기준으로 계산된 날짜입니다.
- HCIS의 일반 Published on 표기는 별도 권·호일/온라인일 근거가 없는 경우 종류 미확인 출판일로 남깁니다. 날짜 자체는 유지합니다. 권·호 배정이 있다는 이유만으로 일반 Published 날짜를 권·호 발행일로 재분류하지 않습니다.
- 조회 후보 수집은 검색원이 제공하는 연도에 의존합니다. 온라인 공개연도와 권·호연도가 다르면 검색원 연도 범위를 넓혀 추가 조회가 필요할 수 있습니다. 기준 전환만으로 아직 수집하지 않은 논문이 생성되지는 않습니다.


## 온라인판·인쇄판 ISSN 구분

- 온라인판 eISSN, 인쇄판 pISSN, 판을 연결하는 ISSN-L을 분리 보관합니다. Crossref의 명시적 매체 유형을 활용하며 OpenAlex의 번호 순서, ISSN-L 또는 SCIE 등재 여부로 온라인판/인쇄판을 추정하지 않습니다. 유형이 없거나 충돌하면 매체 미확인입니다. 한 종류만 확인돼도 다른 판이 없다는 뜻은 아닙니다.
- 논문 목록과 수정 창에 매체별 번호·출처가 표시됩니다. 화면의 **ISSN 기준**에서 **목록의 첫 번째 ISSN(기본값)** 또는 **ISSN-L 우선**을 선택합니다. ISSN-L 우선에서 ISSN-L이 없으면 처음 받은 목록의 첫 번째 번호를 사용합니다. 표·CSV·Excel에도 같은 번호 한 개를 표시합니다. 매체 분류로 번호 순서를 바꾸지 않으며 직접 수정한 ISSN은 유지합니다. 나머지 번호는 매체 구분 및 SCIE 대조용으로 보관하고, 양식에서 **온라인 ISSN (eISSN)**, **인쇄 ISSN (pISSN)**, **연결 ISSN (ISSN-L)**, **ISSN (온라인 우선)**, **ISSN 매체 구분**을 선택할 수 있습니다. Excel의 eISSN / pISSN / ISSN-L 머리글도 자동 매칭합니다.
- 선택은 브라우저, 저자 즐겨찾기와 양식 프리셋에 보관합니다. 기존 저장 항목에 ISSN 기준이 없으면 첫 번째 ISSN으로 불러옵니다. 기준을 반복해서 바꾸거나 출판정보를 보완해도 원본 첫 번호를 보존하며 표·ISSN 정렬·CSV·Excel에 동일한 선택을 적용합니다. 사용자가 별도 열로 선택한 ‘ISSN (온라인 우선)’은 확인된 eISSN, pISSN, 매체 미확인 번호 순으로 사용합니다. eISSN 전용 열은 온라인판 확인이 없으면 빈칸을 유지합니다. 출력 열의 선택과 무관하게 SCIE 대조에는 전체 ISSN을 사용합니다. 직접 수정·삭제한 ISSN은 재조회로 덮어쓰지 않습니다.
- ISSN의 매체와 출판일 종류는 별개입니다. 온라인판에도 권·호가 있을 수 있으므로 eISSN만으로 일반 Published 날짜를 온라인 날짜로 분류하지 않습니다. 출판일은 선택한 권·호/온라인 우선 기준을 따르며 하나만 있으면 그 날짜를 사용합니다.
